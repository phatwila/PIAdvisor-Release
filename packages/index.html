What is new in v1.6.0

PIAdvisor now runs on Mac. This release also sends sharper images to the advisor, reuses uploaded images on supported connections, and allows more measurements in each round.

  • PIAdvisor now runs on Mac computers with Apple silicon in PixInsight 1.9.5 or later, alongside Windows and Linux. Install and update it from the same PixInsight repository. PIAdvisor does not support Intel Macs. If you need Intel Mac support, tell us at support@piadvisor.net.
  • Attach View renders the part of the image you see from the image's own pixels and screen stretch. Previews and busy views attach the screen view instead.
  • Pro now offers Full resolution. Supported models receive images up to 6000 pixels on the longest side. Other models receive images up to 2048 pixels. The advisor sees fine detail such as star shapes in the corners and noise in faint areas.
  • Supported connections reuse uploaded images in later messages. PIAdvisor asks the provider to delete uploaded images when they leave the chat, and the images expire after 24 hours. You can turn this off in LLM Settings.
  • Attached views show their history step and the last process, so the advisor can tell two states of the same image apart.
  • Pro and Trial allow up to 32 measurements per round. That fits stars, background and FITS-header checks on each of five masters in one round.
  • Every edition can set Tool rounds to 0 for answers without measurements. Free allows 0 to 2 measuring rounds per answer, with up to 6 measurements in each round.
  • Export Chat adds the export date, PIAdvisor version, edition, and current provider and model beneath the title.
  • Better advice for HaRGB combination, gradient correction after color calibration, and loading process settings.
  • Fixes for window sizing and processing history details.
