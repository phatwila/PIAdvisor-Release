Install PIAdvisor in PixInsight

PIAdvisor installs through the PixInsight update system on Windows, Linux and Mac. Add this repository once. PixInsight then installs the module and every later update for you.

Install in four steps

  1. In PixInsight, select Resources > Updates > Manage Repositories.
  2. Click Add, paste the repository URL, then click OK.
  3. Select Resources > Updates > Check for Updates. Apply the update, then restart PixInsight.
  4. Open Process > PIAdvisor > PIAdvisor. In LLM Settings, select your provider, type your API key and click Fetch Models. The documentation has the details.

Requirements

  • Windows or Linux (x64): PixInsight 1.8.9 or later.
  • Mac with Apple silicon: PixInsight 1.9.5 or later. PIAdvisor does not support Intel Macs.
  • An API key from OpenAI, OpenRouter or Google Gemini, or a local model server such as Ollama or LM Studio. Your provider bills hosted usage directly.

Free and Pro

One module runs both editions. To activate Pro or a free 60-day trial, click the Preferences (wrench) button in the PIAdvisor panel and type your license key.
