PIAdvisor

By Author: Ray Detwiler

PIAdvisor answers processing questions inside PixInsight. It sends your question and a snapshot of your open images to the AI model you select. The model can also measure your images while it answers. [more]

1 Introduction

[hide]

PIAdvisor connects PixInsight to an AI model through OpenAI, OpenRouter, Google Gemini, or a local OpenAI-compatible server such as Ollama or LM Studio. For each question, PIAdvisor collects context from your open images: FITS keywords, processing history, astrometric solution, screen stretch and image statistics. It sends this context with your question, so the answer applies to your image and not to an average image.

Typical questions:

  • What is the next processing step for this image?
  • Is there a gradient, and should I remove it before stretching?
  • Which parameters suit this image, given its statistics?
  • Write an AstroBin description from my acquisition data.

PIAdvisor uses your own provider account. Your questions, images and measurements go from PixInsight directly to the provider you select. They do not go through PIAdvisor servers.

2 Description

[hide]

2.1 Panel Layout

The PIAdvisor panel has a toolbar and three sections:

Toolbar

The image selector, the pin button, and the Workspace Mode toggle with its refresh button.

Advisor Chat

The conversation, the message box, the attachment buttons (Attach View, Screenshot) and the buttons Send, Cancel, New Chat and Export Chat. A status line below the buttons shows what PIAdvisor is doing.

Context Snapshot

The prepared image context that goes with your next question. Open this section to see exactly what the model receives.

LLM Settings

The provider, model and behavior settings. See Parameters.

2.2 Key Features

Image context

PIAdvisor reads image dimensions, FITS keywords, processing history, astrometric solution, ICC profile, screen stretch and statistics. File paths and user names in history entries are removed before sending.

Workspace Mode (Pro)

Sends one snapshot of all open images, for example L, R, G and B masters, an SHO set, or a starless image and its stars.

Measurements

The model can measure your open images while it answers: star FWHM and eccentricity, background noise and gradients, statistics, stretch previews, history steps, process parameters and FITS keywords. The tools only read data.

Image attachments

Attach a view, an image file or a pasted screenshot for models that accept images.

Rich formatting

Answers use colored callouts, tables, code blocks with a copy button, links that open PixInsight processes, and web links that open your browser. The chat follows PixInsight's light or dark interface.

Your own provider

OpenAI, OpenRouter, Google Gemini, and any OpenAI-compatible server, including local servers.

3 Parameters

[hide]

3.1 Provider

The service that runs the model:

OpenAI

The OpenAI API (api.openai.com).

OpenRouter

One API key for models from many vendors (openrouter.ai).

OpenAI-compatible

Any server that uses the OpenAI chat completions format, for example Ollama, LM Studio, llama.cpp or vLLM.

Google Gemini

The Gemini API. It needs a Google AI Studio API key.

Each provider keeps its own endpoint URL, API key and model.

3.2 Endpoint URL

The base URL of the provider API. PIAdvisor sets it when you select a provider. Change it for a proxy, a private deployment or a local server on another port.

3.3 API key

The key from your provider account. Cloud providers need a key. Local servers usually do not.

PIAdvisor stores API keys in files in the PIAdvisor folder of the PixInsight settings directory, not in the PixInsight settings registry. API keys are never included in chat exports.

3.4 Model

The model identifier, for example gpt-6.1-sol, gemini-2.5-pro or openrouter/auto. Click Fetch Models to load the models that your provider offers, or type an identifier. For a local server, type the exact name of a model that the server has loaded.

3.5 Enable visual analysis

The full label is Enable visual analysis (sends compressed preview image). When this option is on, you can attach images, and PIAdvisor sends them to the model as resized JPEG previews. When it is off, the attachment buttons are not available.

3.6 Vision max pixels

The largest side, in pixels, of each image that PIAdvisor sends to the model. The values are 512, 768, 1024, 1536 and 2048. Free: up to 1024. Pro and Trial: up to 2048, default 2048. Larger values show more detail and use more tokens.

3.7 Image limit

The most images that stay in the conversation for later turns. 0 keeps only the images of the current message. Free: up to 5. Pro and Trial: up to 20, default 6. The newest images have priority.

3.8 Include history snapshot

Adds a summary of the latest processing steps of each image to the context. The summary can include parameter values. With this information, the model knows what you already did.

3.9 History steps

The most processing steps per image in the history summary. 0 sends no history. Free: up to 5. Pro and Trial: up to 20, default 10.

3.10 Enable rich formatting

The full label is Enable rich formatting (callouts, tool links). When this option is on, the model writes callouts, process links, tables and code blocks, and PIAdvisor shows them with styles. Turn it off for a small model that does not follow the formatting instructions.

3.11 Stream responses (beta)

Shows the answer while the model writes it. If the connection fails before any text arrives, PIAdvisor tries again once without streaming.

3.12 Let the advisor fetch image data

Lets the model measure your open images while it answers. This option is on by default. The tools only read data and do not change your images. See Letting PIAdvisor Measure.

3.13 Tool rounds

The most measuring rounds in one answer. In each round, the model can request up to 6 measurements. Free: 2. Pro and Trial: 1 to 12, default 4. Most answers use one round. Each round sends the earlier results of the answer again, so more rounds use more tokens. When the results become large, PIAdvisor tells the model to answer with the data it has.

3.14 About my setup

Your equipment and preferences, sent with each question so that you do not repeat them. For example: Mono LRGB and narrowband, 0.9"/px. I do not use ML-based processes. I follow a video course; keep its tool order. PIAdvisor does not recommend processes that you say you avoid. At most 600 characters.

3.15 Formatting template (Markdown)

The formatting instructions that PIAdvisor adds to the system prompt when Enable rich formatting is on. To restore the built-in template, select Template in the reset list, then click Reset.

3.16 System prompt

The instructions that the model receives at the start of each request. PIAdvisor includes a detailed built-in prompt. You can change it, but changes can make the answers worse. To restore the built-in prompt, select Prompt in the reset list, then click Reset.

The system prompt and the formatting template update together. When a PIAdvisor release includes new prompts, PIAdvisor updates each unchanged text automatically. If you changed the system prompt or the formatting template, PIAdvisor asks once for each new prompt version. We strongly recommend the new prompts, because new features and the quality of the answers depend on them. Before PIAdvisor replaces your version, it saves a copy as system-prompt-custom-<date>.txt or formatting-template-custom-<date>.txt in the PIAdvisor folder of the PixInsight settings directory.

3.17 Settings buttons

Test

Sends a short request with the current endpoint URL, API key and model, and shows the result in the status line.

Fetch Models

Loads the model list from the provider.

Save

Saves all settings.

Reset

Select an item in the reset list, then click Reset. Defaults restores all settings and removes the saved API keys, the custom prompt, the formatting template and About my setup. Your license stays active. Template and Prompt restore only that text. A reset cannot be undone.

3.18 Installed version

The Installed version line at the bottom of LLM Settings shows the PIAdvisor release that you use and the state of the prompts, for example Installed version: 1.5.0 | Prompt: default v8.8. Point to it to see the full build identifier. Give this identifier when you ask for support.

4 Usage

[hide]

4.1 Quick Start

  1. Open PIAdvisor from Process > PIAdvisor > PIAdvisor or from the Process Explorer.
  2. Expand the LLM Settings section.
  3. Select a Provider.
  4. Type your API key. A cloud provider needs a key. A local server usually does not.
  5. Click Fetch Models, then select a model. You can also type a model identifier.
  6. Click Test to check the endpoint, key and model.
  7. Click Save.

4.2 Having a Conversation

  1. Open one or more images in PixInsight. Plate-solved images with processing history give the best context.
  2. Type your question in the message box.
  3. Press Ctrl+Enter or click Send.
  4. PIAdvisor collects the context of the selected image, or of all open images in Workspace Mode, and sends it with your question.
  5. The answer appears in the chat. Click a process link, for example SpectrophotometricColorCalibration, to open that process.

Click Cancel to stop a reply. Click New Chat to start a new conversation.

Point to a message to show its buttons. Copy copies the message as Markdown. Your own messages also have Edit: change the text or the attached images, then click Apply Edit. The edited message replaces that turn and all later turns. Cancel Edit restores the conversation.

Answers name problems first, the most serious first. PIAdvisor praises a step only when a measurement or the image shows that it worked, and it does not grade your image. If you only share an image ("Here is the red channel"), the answer is short. For a full review, ask for analysis, advice or next steps.

When ImageSolver, SPCC or WBPP fails, paste the error text from the Process Console into your question. PIAdvisor cannot read the console, PixInsight preferences or WBPP log files. It checks what the open image shows: the image scale from the FITS keywords, the start coordinates and the stars.

4.3 Choosing the Image

The image selector in the toolbar follows the active image window. To keep the context on one image while you work in other windows, select that image in the list, or click the pin button. Click the pin button again to follow the active image.

Open the Context Snapshot section to see the context that goes with your next question. The first line shows the mode, the number of images, the active image and the capture time.

4.4 Using Workspace Mode (Pro)

Click the Workspace Mode button in the toolbar to turn the mode on or off. With a Pro or trial license, Workspace Mode is on until you turn it off. In Workspace Mode:

  • The context includes all open image windows, not only the active image.
  • The context shows how the images relate, for example a starless image and its stars, or L, R, G and B masters.

PIAdvisor captures a new workspace snapshot each time you send a question. Click the refresh button next to Workspace Mode to capture one without sending, for example to check it in Context Snapshot.

4.5 Attaching Images

To attach images, turn on Enable visual analysis in LLM Settings. Use a model that accepts images.

Attach View

Attaches the visible area of the selected or pinned image window, as it shows on screen with its screen stretch. This is a screen capture, not the full-resolution image.

Screenshot

Attaches an image file from your computer, for example a screenshot, an annotated image or a reference image.

Paste (Windows and Linux)

Click the message box and press Ctrl+V to attach a PNG or JPEG image from the clipboard. The text in the message box stays. When the clipboard holds an image and text, PIAdvisor attaches only the image. On Linux, there is no right-click Paste command.

Attached images show as cards above the message box. Click the remove button on a card to remove that image before you send. Images load in the background; wait until loading finishes before you send or edit a message.

PIAdvisor resizes each image to the Vision max pixels limit before it sends it. Smaller images are not enlarged. The original image stays on your computer. Click an image in the chat to open it in the Attachment Viewer: click to zoom, drag to move, and click again to fit. Fit resets the view. Close or Escape returns to the chat.

Earlier images stay in the conversation up to the Image limit. The newest images have priority. To remove an image from a sent message, click Edit on that message, remove the image, then click Apply Edit.

4.6 Reading Answers

While PIAdvisor works, the answer header shows the elapsed time, for example Working for 30s. When the answer is complete, it shows Worked for 1m 12s. A stopped answer shows Stopped after ..., and a failed answer shows Failed after ....

A muted line at the end of each answer shows the tokens it used and the number of requests, for example 18.2k tokens in (15.1k cached), 1.1k out, 3 requests. The cached part is the part of the request that the provider reused from earlier turns at a lower price. OpenRouter also shows the cost. When a provider does not report token counts, this line does not show.

Answers use these styles. The welcome message shows examples of each.

Callouts

Colored boxes: Action (green) for the next step, Tip (blue), Note (gray), Warning (amber) for a wrong order or a step that degrades the result, and Caution (red) for a risk of data loss.

Tables

Short comparisons, for example star measurements per image. A table that is wider than the panel scrolls sideways.

Links

A process link opens the process in PixInsight. A web link (https only) opens your browser.

Code blocks

PixelMath expressions and parameter sets, with a copy button.

4.7 Letting PIAdvisor Measure

Some answers need a number that you would otherwise look up yourself, for example the FWHM from SubframeSelector, the statistics of a region, or the number of frames from the FITS keywords. With Let the advisor fetch image data on, the model gets these numbers with read-only tools while it answers.

A line above the answer, for example [Checking: stars (Image01)...], shows what the model measures. When the answer is complete, click Show measured values to see the exact values the model received. Show parameters lists the process parameters the model looked up. Later questions in the same chat reuse the key values, for example FWHM and noise. When you process an image after a measurement, PIAdvisor tells the model to measure again.

In PIAdvisor Free, the model measures only the image in the context: the selected or pinned image and its previews. To compare two images in Free, ask about the first image, select the second image in the image list, and ask again. The values from the first answer stay in the chat. With a Pro or trial license, Workspace Mode measures all open images in one question.

The tools need a model that supports function calling. When a model does not, PIAdvisor answers from the context snapshot and tells you.

Measurements

Tool

What it measures

Stars

FWHM, eccentricity, star count, PSF Signal Weight, PSF SNR, tilt and elongation, with the same method as SubframeSelector

Background

Noise per channel, gradient strength and direction, color balance, and, for a plate-solved image, whether the gradient points toward the horizon

Statistics

Any open image, or a region of it

Stretch preview

Clipping that a black point, white point or midtones change will cause

History

All parameters of one processing step

Process parameters

The parameters of an installed process

FITS header

All keywords. Site, observer and serial-number values are removed.

When noise reduction, for example TGVDenoise, is in the history, PIAdvisor does not estimate how much more integration time you need. Noise reduction lowers the measured noise, so that estimate is too low.

4.8 Exporting

Click Export Chat to save the conversation. Select the file type in the save dialog:

Markdown files (.md)

The conversation with its formatting.

Text files (.txt)

The same content as a plain text file.

Provider metadata only (.json)

Technical data from the provider about the last request and the last Test, without the conversation. Support can ask you for this file.

5 Licensing

[hide]

The Free features need no license. Pro features need an activated Pro or trial license key.

5.1 Activating a License

  1. Open PIAdvisor and click the Preferences (wrench) button at the bottom of the panel.
  2. In the PIAdvisor License dialog, type your key in License Key (format PRO-XXXX-XXXX-XXXX or TRIAL-XXXX-XXXX-XXXX).
  3. Click Activate.

PIAdvisor checks the key with the PIAdvisor license server once. The Pro features unlock immediately. After activation, PIAdvisor checks the license offline. The status line in the dialog shows Activated (Pro), or Activated (Trial) with the end date.

Activation sends the license key, the Installation ID shown in the dialog, and the PIAdvisor version. The Installation ID comes from the location of your PixInsight settings folder, not from your hardware.

5.2 Device Limits

You can activate a Pro license on 3 devices at the same time, and a trial license on 2 devices. When you reach the limit, activation fails with a message. Deactivate another device first.

5.3 Trial Licenses

A trial gives the Pro features for 60 days. PIAdvisor sends the trial key to your email address.

5.4 Deactivating a Device

To free an activation:

  1. Open PIAdvisor on the device that you want to deactivate.
  2. Click the Preferences (wrench) button.
  3. Click Deactivate and confirm.

5.5 Purchasing a License

To buy a license, go to the PIAdvisor website. You receive the license key by email. Activate it in the PIAdvisor License dialog.

6 Model Selection

[hide]

Click Fetch Models to load the model list from your provider. If the provider does not list its models, type the exact model identifier.

For a new configuration, PIAdvisor uses these models:

  • OpenAI: gpt-6.1-sol
  • Google Gemini: gemini-2.5-pro
  • OpenRouter: openrouter/auto
  • OpenAI-compatible: no default. Type the name of a model that your server has loaded, for example llama3.2.

For measurements, use a model that supports function calling. For attachments, use a model that accepts images.

7 Troubleshooting

[hide]

7.1 Connection Errors

Connection failed or a timeout

Make sure that the endpoint URL is correct, then click Test. For a local server, make sure that the server runs and that your firewall allows the connection.

"No reply within 15 s"

The provider is slow or overloaded. Test waits 15 seconds. Chat requests wait longer.

401 Unauthorized

The API key is not valid or has expired. Check it in your provider account.

429 Too Many Requests

You reached the rate limit of your provider. Wait and try again, or change your provider plan.

Model not found

The provider does not offer this model identifier. Click Fetch Models and select a model from the list.

7.2 Empty or Incomplete Answers

  • Turn off Stream responses (beta) and send the question again.
  • A local model can have a small context window. Decrease History steps and Image limit, or turn off Workspace Mode.
  • Look for error messages in the Process Console.

7.3 Asking for Support

Include the Installed version build identifier, the provider and the model. If support asks for it, attach the Provider metadata only file from Export Chat.
